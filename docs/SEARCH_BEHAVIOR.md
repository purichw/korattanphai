# ข้อกำหนดการค้นหาข้อมูล

สถานะการเผยแพร่และหลักฐานการตรวจสอบล่าสุด: ดู [บันทึกการส่งมอบ](HANDOFF.md)

การค้นหากลางอ้างอิงหลักการของ Shane Thai: ค้นหาหลายประเภทในครั้งเดียว
แสดงที่มา กรองผลลัพธ์ เลือกวิธีจับคู่ เปิดปลายทางจริง และบันทึกประวัติเมื่อผู้ใช้
ยืนยันการค้นหา พร้อมล้างประวัติได้ ข้อความใช้ภาษาไทยทางการและรูปแบบของโคราชทันภัย

## ขอบเขตและชื่อซ้ำ

- โหลดส่วนค้นหาเมื่อเปิดใช้งาน พร้อมข้อความระหว่างโหลดและปุ่มปิด
  หน้าหลักไม่ต้องรอส่วนค้นหา และมีการตรวจเพดานขนาดไฟล์แยกในขั้นตอน build

- จังหวัดนครราชสีมา 1 จังหวัด 32 อำเภอ และ 289 ตำบล จาก `admin_hierarchy.json`
  รวมถึงหน้าพยากรณ์ภัยแล้งและเครื่องมือส่งออก Excel ที่เปิดใช้จริงในโหมดฐานข้อมูล
- ใช้รหัสและระดับพื้นที่เป็นตัวระบุ ไม่รวมรายการเพียงเพราะชื่อเหมือนกัน
- “ปากช่อง” พบอำเภอปากช่อง ตำบลปากช่อง และตำบลอื่นในอำเภอปากช่อง
  ชื่อหรือรหัสที่ตรงโดยตรงเรียงก่อนรายการที่ตรงกับบริบท
- แสดงระดับ ชื่อ อำเภอ/จังหวัด รหัสพื้นที่ และข้อความที่ทำให้ค้นพบ
- หน้าและเครื่องมือเป็นอีกประเภทหนึ่ง แม้เกี่ยวข้องกับจังหวัดเดียวกัน
- ไม่รวมข้อมูลวิจัยที่ยังไม่เปิดใช้ เอกสารส่วนตัว หรือเมนูเก่าที่ไม่ได้ใช้งาน

## คำค้นหา ชื่อเรียกอื่น และหัวข้อ

| ประเภท | ตัวอย่าง | หลักการ |
| --- | --- | --- |
| ข้อมูลหลัก | ปากช่อง, 3021, 302101 | ใช้ชื่อและรหัสจริง |
| ชื่อเรียกอื่น | โคราช, Korat, Pak Chong | คำเรียกที่กำหนดไว้และชื่ออังกฤษที่มีในต้นฉบับ |
| บริบทพื้นที่ | ตำบลในอำเภอปากช่อง | ค้นหาพื้นที่ย่อยผ่านชื่ออำเภอหรือจังหวัดได้ |
| หัวข้อ | แผนที่, พยากรณ์ภัยแล้ง, รายงาน, ส่งออกข้อมูล | ชุดคำกลาง ค้นหาและกดกรองต่อได้ |

- “มีคำค้นหาอยู่ภายใน” เป็นค่าเริ่มต้น รองรับหลายคำในชื่อ บริบท หรือหัวข้อของรายการเดียวกัน
- “ตรงกับคำค้นหาทั้งหมด” ต้องตรงกับข้อมูลค้นหาหนึ่งค่า รวมชื่อเรียกอื่นหรือบริบท
  โดยแสดงข้อความที่ตรงกำกับ ไม่ใช่การเดาคำสะกด
- ภาษาไทยล้วนอย่างน้อย 2 ตัวอักษรตามระบบอ้างอิง รองรับรหัสเลขไทยและเลขอารบิก
  ไม่ตัดสระหรือวรรณยุกต์ไทย และไม่เดาชื่อพื้นที่เมื่อสะกดผิด
- กรองประเภทข้อมูล อำเภอ และหัวข้อ แสดงจำนวนผลลัพธ์และปุ่ม “ล้างตัวกรอง”
- บนมือถือเริ่มด้วยตัวกรองแบบย่อ กด “แสดงตัวกรอง” เพื่อปรับเงื่อนไขได้
- เปลี่ยนคำค้นหาหรือวิธีค้นหาเริ่มตัวกรองใหม่ แสดงครั้งละ 24 รายการและเพิ่มได้
- ระดับความเสี่ยง เดือน และระยะพยากรณ์ไม่ใช่แท็กถาวรของพื้นที่

## ประวัติการค้นหา

- “คำค้นหาล่าสุด” บันทึกเมื่อกด “ค้นหา”, Enter, เลือกคำแนะนำ/คำล่าสุด หรือเปิดผลลัพธ์
  การพิมพ์อย่างเดียวยังไม่บันทึก เก็บสูงสุด 6 คำไม่ซ้ำ เรียงล่าสุดก่อน
- localStorage แยกตามรหัสบัญชีบนเบราว์เซอร์นั้น ไม่ส่งไป API หรือซิงก์ข้ามอุปกรณ์
- “ล้างประวัติการค้นหา” ล้างเฉพาะบัญชีปัจจุบัน มีผลหลังเปิดหน้าใหม่
  เมื่อไม่มีประวัติแสดง “คำค้นหาแนะนำ”
- รับการเปลี่ยนประวัติจากแท็บอื่น และอ่านค่าล่าสุดก่อนบันทึกคำใหม่
- ถ้าเบราว์เซอร์ไม่อนุญาตให้ล้าง ต้องแจ้งข้อผิดพลาดโดยไม่แสดงว่าล้างสำเร็จ

## การเปิดผลลัพธ์

- เปิดหน้าต่างค้นหาจากเมนูหลักหรือปุ่มบนอุปกรณ์เคลื่อนที่ ค้นหาได้ทั้งจังหวัด
  ตัวค้นหาเฉพาะแผนที่เดิมยังจำกัดขอบเขตของแผนที่นั้น
- โฟกัสช่องกรอกเมื่อเปิด ปิดด้วยปุ่มหรือ Escape แล้วคืนโฟกัสให้ปุ่มเปิด
- เปิดเส้นทางจริงตามรหัสและ slug รักษาเดือนต้นทาง ระยะพยากรณ์ และตัวเลือกชลประทาน
  หน้าภาพรวมยังเป็นล่วงหน้า 1 เดือนตามสัญญาเดิม
- ตัวกรองอำเภอและความเสี่ยงของหน้าก่อนไม่ติดตามไปซ่อนพื้นที่ที่เพิ่งค้นพบ
- ส่งออกเปิดหน้าต่าง Excel เดิม ไม่มีการดาวน์โหลดอัตโนมัติ
- คำค้นหา/ตัวกรองเป็นสถานะชั่วคราวในหน้าต่าง ปิดแล้วเปิดใหม่เริ่มที่ประวัติ/คำแนะนำ
  ไม่บันทึกคำค้นหาและตัวกรองลง URL

## โค้ดและการตรวจสอบ

- `src/workspaceSearch.ts`: ดัชนี การจับคู่ ปลายทาง และประวัติ
- `src/components/WorkspaceSearch.tsx`: ผลลัพธ์ ตัวกรอง และประวัติ
- `src/AuthenticatedApp.tsx`: จุดเปิดค้นหากลางและหน้าต่างส่งออก
- ใช้ `AppSelect` และ `WorkspaceDialog` เดิม โดยเพิ่ม `closeLabel` แบบไม่เปลี่ยนค่าเริ่มต้น
- `ForecastExcelExport.openRequest`: เปิดจากการค้นหาโดยใช้กระบวนการส่งออกเดิม
- `tests/workspaceSearch.test.ts`: ชื่อซ้ำ รหัส เส้นทาง คำค้น ประวัติ และข้อผิดพลาดการจัดเก็บ
- `e2e/workspace-search.spec.ts`: ผลลัพธ์ ตัวกรอง ปลายทาง ประวัติ การล้าง แป้นพิมพ์
  และการเปิดส่งออก ด้วยข้อมูลทดสอบในเครื่องบน desktop/mobile
